# E0012: a name declared twice

Within a POU, each variable name is declared once; across the project,
each POU and type name, and each global variable, once. IEC compares
names ignoring case (Ed.3 6.1.2), so `Count` and `COUNT` are the same
name.

```
VAR
    count : INT;
    Count : DINT;     (* E0012 *)
END_VAR
```

A global variable is declared once in each scope that sees it (Ed.3
6.5.2.2): two CONFIGURATIONs may each have a `g`, and so may two
RESOURCEs of one configuration, each its own, and two PROGRAMs; a
resource declaring a name its configuration declares, a PROGRAM one
its resource or configuration declares, or any of them a name of a
global variable list outside them, is E0012. Where one of them is CONSTANT, all are, with the
same integer value: a constant is worked out once, whichever scope
runs the code that names it (docs/dependencies.md).
