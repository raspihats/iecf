# E0012: a name declared twice

Within a POU, each variable name is declared once; across the project,
each POU and type name, and each global variable, once. IEC compares
names ignoring case (Ed.3 6.1.2), so `Count` and `COUNT` are the same
name.

```
VAR
    count : INT;
    Count : DINT;     (* E0012 *)
END_VAR
```

A global variable is declared once in each scope that sees it (Ed.3
6.5.2.2): two CONFIGURATIONs may each have a `g`, and so may two
RESOURCEs of one configuration, each its own; a resource declaring a
name its configuration declares, or either one a name of a global
variable list outside them, is E0012.
