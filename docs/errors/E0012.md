# E0012: a name declared twice

Within a POU, each variable name is declared once; across the project,
each POU and type name, and each global variable, once. IEC compares
names ignoring case (Ed.3 6.1.2), so `Count` and `COUNT` are the same
name.

```
VAR
    count : INT;
    Count : DINT;     (* E0012 *)
END_VAR
```
