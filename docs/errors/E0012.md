# E0012: a name declared twice

Within a POU, each variable name is declared once; across the project,
each POU and type name, and each global variable, once. IEC compares
names ignoring case (Ed.3 6.1.2), so `Count` and `COUNT` are the same
name.

```
VAR
    count : INT;
    Count : DINT;     (* E0012 *)
END_VAR
```

A global variable is declared once in its scope (Ed.3 6.5.2.2): two
CONFIGURATIONs may each have a `g`, and so may two RESOURCEs of one
configuration and two PROGRAMs, each its own. One named as a global
further out - a resource's as its configuration's, a PROGRAM's as its
resource's - is no error: it hides that one where it is seen, as a
local name hides a global one in CODESYS (docs/dependencies.md). Where
one of them is CONSTANT, all are, with the same integer value: a
constant is worked out once, whichever scope runs the code that names
it.
