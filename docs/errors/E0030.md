# E0030: a method or variable its access specifier keeps from here

A method, or a variable of a CLASS's or FUNCTION_BLOCK's VAR section, is
used where its access specifier does not let it be (Ed.3 6.6.5.9,
6.6.5.10):

- `PUBLIC`: anywhere the type can be used.
- `PROTECTED`: in the type itself and the types derived from it. A
  method or VAR section without a specifier is PROTECTED (Ed.3; OO.md
  D1), where CODESYS and TwinCAT make it PUBLIC.
- `PRIVATE`: in the type itself only.
- `INTERNAL`: in the type's namespace.

```
CLASS Counter
  METHOD Count     (* PROTECTED: no specifier *)
  END_METHOD
END_CLASS
...
c.Count();         (* E0030 *)
```

Write `METHOD PUBLIC Count` to call it from outside; `VAR PUBLIC` for a
variable read or written from outside, as `c.limit`.
