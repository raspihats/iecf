# W0008: an array given fewer or more initial values than it has elements

An array's initial value is a list, in which `n(...)` repeats a value
or a list of values (Ed.3 6.4.4.5.2). The list need not be as long as
the array: "If the number of initial values given in the initialization
list exceeds the number of array entries, the excess (rightmost) initial
values shall be ignored. If the number of initial values is less than
the number of array entries, the remaining array entries shall be
filled with the default initial values for the corresponding data type.
In either case, the user shall be warned of this condition".

```
VAR
  a : ARRAY[0..5] OF INT := [1, 2];          (* W0008: 2 for 6; a[2] to a[5] are 0 *)
  b : ARRAY[0..1] OF INT := [1, 2, 3];       (* W0008: 3 for 2; the 3 is ignored *)
  c : ARRAY[0..5] OF INT := [2(1, 2, 3)];    (* 1, 2, 3, 1, 2, 3 *)
  d : ARRAY[0..5] OF INT := [1, 2, 4(0)];    (* as a, said in full *)
END_VAR
```

The program is compiled as the standard says. To say that the rest is
meant, write it: `[1, 2, 4(0)]`, or `4()` for the type's own initial
value.
