# E0002: a comment that is never closed

A comment opened with `(*` or `/*` runs until its matching `*)` or `*/`.
Comments nest (Ed.3 Table 3, features 3a and 3b), so every `(*` inside a
comment needs its own `*)`.

```
(* counts the boxes (* every scan *)
x := x + 1;       (* still inside the first comment: E0002 at its start *)
```

iecf reports the comment once, at its start, and stops reading the
file there rather than guessing where it was meant to end.
