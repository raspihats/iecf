# E0018: a name the standard reserves for a type, function or block

Data type names (`DT`, `TOD`, `INT`), standard function names (`LT`,
`ADD`, `INT_TO_REAL`) and standard function block names (`TON`, `CTU`)
are keywords: they "shall not be used for any other purpose, for
example, variable names" (Ed.2 2.1.3 and Table C.2; Ed.3 6.1.3).

```
VAR dt : TIME; END_VAR       (* E0018: DT is a data type *)
VAR cycle_dt : TIME; END_VAR (* fixed *)
```

iecf reserves one name of its own: a CONFIGURATION is not named IECF.
Its C would be `iecf.h` and names starting `iecf_`, which are the
runtime header's (docs/c-output.md §2).

`--extension shadowing` lets a POU's variable be named as a standard
function block or function (`tp : BOOL;`), as CODESYS and TwinCAT do:
in that POU the name is the variable. A data type's name, THIS and
SUPER stay reserved, and so does a standard function's name for a
FUNCTION of the project
([extensions](../extensions.md#shadowing-a-pous-variable-named-as-a-type-a-pou-or-a-standard-block-or-function)).
