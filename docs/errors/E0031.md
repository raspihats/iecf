# E0031: a class, method, THIS or specifier where Ed.3 does not allow it

Ed.3's object orientation (6.6.5 to 6.6.7) puts each of its parts in
one place; this one is somewhere else:

- a CLASS declares only `VAR` and `VAR_EXTERNAL` sections; its methods
  have the inputs and outputs (6.6.5.2);
- an access specifier stands on a CLASS's or FUNCTION_BLOCK's `VAR`
  section, not on its inputs, outputs or externals, nor on a method's
  variables (6.6.5.10, 6.6.7.2.6);
- `OVERRIDE` on a method that has no base method to override
  (6.6.5.5.5, error 4);
- `FINAL` and `ABSTRACT` together;
- `THIS` outside a method or a function block's body (6.6.5.7.2);
- an instance of a CLASS, or of a FUNCTION_BLOCK with methods, copied
  with `:=`, made an input or output, or a variable of a FUNCTION or a
  method: it is passed as a `VAR_IN_OUT` instead (OO.md D11). A copy
  would cut a derived instance down to its base.
