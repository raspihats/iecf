# W0019: an interface named twice in IMPLEMENTS, counted once

Only with `--extension codesys-oo` (in the `codesys` pack). Ed.3 lists
what a FUNCTION_BLOCK's or CLASS's IMPLEMENTS may not name (6.6.6.4)
and says nothing of a name written twice; without the extension iecf
refuses it, [E0012](E0012.md). TwinCAT compiles it, and the extension
takes the interface once, with this warning:

```
CLASS Dialog IMPLEMENTS IAnswer, IAnswer   (* W0019 *)
  ...
END_CLASS
```

TcOpen's `TcoInputDialog` is written so. Nothing changes for the type:
it implements the interface, its methods are checked once against it.
To silence it, name the interface once.

An INTERFACE whose EXTENDS names one twice stays E0012.
