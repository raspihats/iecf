# W0016: a DT literal's fraction of a second, dropped

Only with `--extension dt-literals` (in the `codesys` pack). A DT holds
whole seconds in iecf ([Implementer
choices](../dependencies.md#the-time-types-ranges-and-resolution-ed3-642-table-10)),
as CODESYS's does ("The resolution for `DT` is 1 second"), so a DT
literal with a fraction of a second other than 0 is
[E0020](E0020.md). CODESYS's own examples write one
(`DT#2018-08-08-13:33:20.5`), and TwinCAT compiles TcOpen, which has
`DT#2013-05-09-13:29:20.500`. With the extension the fraction is
dropped, rounding down, as iecf drops one in DT arithmetic, and this
warning says where.

```
VAR t : DT; END_VAR
t := DT#2013-05-09-13:29:20.500;   (* W0016: DT#2013-05-09-13:29:20 *)
```

To silence it, leave the fraction out, or hold the time in an LDT,
which counts nanoseconds.
