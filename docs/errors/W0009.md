# W0009: a CASE label that earlier labels already cover

A CASE runs the first arm one of whose labels matches the selector (Ed.3
7.3.3.3.3). A label every value of which earlier labels already take, in
its own arm or in one before it, can never be the one that matches: it
selects nothing, and an arm made only of such labels never runs. The
standard does not make this an error, and the program is compiled as
written; the warning says that the label is not doing what it seems to.

```
CASE i OF
  1..10: a := 1;
  5:     a := 2;          (* W0009: 1..10 takes 5; a := 2 never runs *)
  8..12: a := 3;          (* no warning: 11 and 12 are its own *)
  3, 3:  a := 4;          (* W0009 on each 3: 1..10 takes it *)
END_CASE;

CASE c OF
  red, green: a := 1;
  COLOR#red:  a := 2;     (* W0009: red is taken *)
END_CASE;
```

The labels are compared where the checker knows their values: those of
an integer or bit string selector by value, a range as every value in
it; those of an enumeration by the value's name. A label of a real, a
STRING, a CHAR, a duration or a date is not compared. A label that only
partly overlaps earlier ones is not warned of, as it still selects the
rest.

To keep the arm, give it a value no earlier label takes, or move it
before the label that takes its values.
