# E0022: an address where the standard does not allow one

A FUNCTION has no located variables: it keeps nothing between calls
(Ed.2 Table E.1).

`AT %I*`, `AT %Q*` and `AT %M*` leave the address for the configuration
to give in `VAR_CONFIG` (Ed.3 6.5.5.4). `VAR_CONFIG` reaches a variable by
its name, through the program instance and the function block instances
it sits in, so the `*` is allowed only where that path exists:

- in `VAR` of a PROGRAM or FUNCTION_BLOCK, under a name (Ed.3 Annex A,
  `Loc_Partly_Var_Decl`; CODESYS documents the same);
- in a field of a structure type (Ed.3 6.4.4.8), when the structure is
  declared there.

Not in `VAR_OUTPUT`, `VAR_INPUT`, `VAR_IN_OUT`, `VAR_TEMP` or
`VAR_EXTERNAL`, not in a
global (a global has one instance: write its address in full), not inside
an array (a path names no element), and not in a body: a body uses the
variable's name.

The `*` takes the place of the size and the numbers both: `%I*`, not
`%IX*` (that is E0004).

```
FUNCTION_BLOCK valve
VAR_OUTPUT open AT %I* : BOOL; END_VAR   (* E0022: not in VAR_OUTPUT *)
VAR       coil AT %Q* : BOOL; END_VAR    (* fine *)
END_FUNCTION_BLOCK
```
