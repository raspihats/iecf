# E0017: a VAR_EXTERNAL that matches no VAR_GLOBAL

`VAR_EXTERNAL` names a global variable declared in a `VAR_GLOBAL`
block of the configuration, a resource, or a global variable list, with
the same type (Ed.3 6.5.2.2). A global declared `CONSTANT` must be
`VAR_EXTERNAL CONSTANT` where it is used (Ed.2 Table E.1).

```
VAR_GLOBAL counter : INT; END_VAR
PROGRAM p
VAR_EXTERNAL count : INT; END_VAR    (* E0017: no global named count *)
END_PROGRAM
```

Which global it is depends on where the POU runs: each CONFIGURATION
has its own, so a POU two configurations run is checked in each, and
the message names the one that lacks it. A POU no configuration runs -
a library's - is checked against every global of the name.

```
CONFIGURATION a
  VAR_GLOBAL count : INT; END_VAR
  RESOURCE r ON PLC TASK t(INTERVAL := T#10ms, PRIORITY := 1); PROGRAM p1 WITH t : p; END_RESOURCE
END_CONFIGURATION
CONFIGURATION b                      (* E0017 at p's count: none in b *)
  RESOURCE r ON PLC TASK t(INTERVAL := T#10ms, PRIORITY := 1); PROGRAM p1 WITH t : p; END_RESOURCE
END_CONFIGURATION
```
