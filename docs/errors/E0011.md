# E0011: a type that nothing declares

A type is elementary (`INT`, `TIME`, ... Ed.3 Table 10), a standard
function block (`TON`, `CTU`, ...), or declared in a `TYPE` block or as
a `FUNCTION_BLOCK` in the project.

```
VAR t : TIMER; END_VAR     (* E0011: no type TIMER - TON? *)
```

A PROGRAM or FUNCTION name is not a type either.
