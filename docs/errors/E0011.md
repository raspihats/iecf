# E0011: a type that nothing declares

A type is elementary (`INT`, `TIME`, ... Ed.3 Table 10), a standard
function block (`TON`, `CTU`, ...), or declared in a `TYPE` block or as
a `FUNCTION_BLOCK` in the project.

```
VAR t : TIMER; END_VAR     (* E0011: no type TIMER - TON? *)
```

A PROGRAM or FUNCTION name is not a type either.

`BIT`, a structure's member one bit wide, is CODESYS's and TwinCAT's,
not a type of Ed.3: the [bit](../extensions.md#bit-codesyss-and-twincats-bit-a-structures-member-one-bit-wide-packed-into-bytes)
extension places it. With it on, a BIT is still E0011 outside a
structure or a function block, and in a structure beside a member of a
named type.
