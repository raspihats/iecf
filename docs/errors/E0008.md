# E0008: Instruction List, removed from IEC 61131-3 in Ed.4

Ed.3 (2013) deprecated Instruction List (Annex B) and Ed.4 (2025)
removed it. iecf compiles the standard as it is now and has no IL.
Rewrite the POU in Structured Text: each IL accumulator sequence is
one ST expression.

```
LD   a          (* IL *)
AND  b
ST   q

q := a AND b;   (* ST *)
```
