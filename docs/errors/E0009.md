# E0009: a part of IEC 61131-3 that iecf does not compile yet

iecf is built in order: the Ed.2 core first, then Ed.3's object
orientation, references and namespaces, then Ed.4's additions (see
PROPOSAL.md §5). The message names the construct. iecf skips it to its
END keyword and checks the rest of the file.

This is a gap in iecf, not a mistake in the program.
