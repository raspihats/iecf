# W0007: an SFC indicator variable, deprecated since Ed.3

An action association may name, after its qualifier, Boolean
"indicator" variables (Ed.3 6.7.4.2, Table 58 field "c"): variables the
action "can" set "to indicate its completion, timeout, error
conditions, etc.". The standard gives them no behaviour of their own:
the action sets the variable in its body, and a transition or anything
else reads it. "The use of the indicator variable is deprecated."

iecf reads one, checks that it is a BOOL variable the POU sees (E0010,
E0013 otherwise), warns, and generates nothing for it: the variable is
an ordinary BOOL.

```
INITIAL_STEP s22 : hv_breaker(N, hv_brkr_closed); END_STEP   (* W0007 *)
TRANSITION FROM s22 TO s23 := hv_brkr_closed; END_TRANSITION
```

Without it, the same chart: name the action alone, `hv_breaker(N)`; the
action still sets `hv_brkr_closed`, and the transition still reads it.
