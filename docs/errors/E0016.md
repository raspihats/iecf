# E0016: a call that does not fit what it calls

A function is called with its inputs either all by name or all in
order (Ed.3 6.6.1.4); a function block is called through an instance,
not by its type name; `:=` passes an input or in-out, `=>` takes an
output; every name must be one of the callee's parameters.

```
VAR t : TON; END_VAR
TON(IN := x, PT := T#1s);     (* E0016: call an instance: t(...) *)
t(IN := x, Q := y);           (* E0016: Q is an output: Q => y *)
```
